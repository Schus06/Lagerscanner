# Lager-Scanner

Barcode-Scanner für das iPhone: scannt mit der Kamera, speichert die Liste auf dem Gerät
und exportiert als Excel (.xlsx) oder JSON.

## Auf GitHub Pages veröffentlichen

1. Auf github.com anmelden → oben rechts **+** → **New repository**
   - Name: `lager-scanner`
   - **Public** auswählen → **Create repository**
2. Auf der neuen Seite auf **uploading an existing file** klicken
3. Alle Dateien aus diesem Ordner hineinziehen
   (index.html, manifest.json, die drei .png-Dateien, README.md) → **Commit changes**
4. **Settings** → links **Pages** → bei *Branch* `main` und `/ (root)` wählen → **Save**
5. Nach 1–2 Minuten erscheint oben die Adresse:
   `https://IHR-BENUTZERNAME.github.io/lager-scanner/`

## Auf dem iPhone

1. Adresse in **Safari** öffnen
2. **Teilen** → **Zum Home-Bildschirm**
3. App über das Symbol starten → **Kamera starten** → Kamera-Zugriff **erlauben**

Hinweis: Die gescannten Daten liegen nur auf dem jeweiligen iPhone.
Regelmäßig als Excel oder JSON exportieren.
